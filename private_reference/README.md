# Private references

Keep proprietary plugin archives, vendor source and other non-redistributable
reference material here or in an equivalent local path. Archives and vendor
directories are gitignored. Record the filename, version, SHA-256 and permitted
usage in a local manifest before using a reference for clean-room adapter work.

The checked-in `acss/4.0.1/` research notes are not a runtime dependency and do
not grant redistribution rights to any vendor code.
