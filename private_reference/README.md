# Private references

Keep actual vendor/plugin evidence, confidential/private source exports,
source-environment evidence, and other material whose redistribution is not
established here or in an equivalent local path. Archives and vendor
directories are gitignored. Record the filename, version, SHA-256, evidence,
and scoped permitted usage in a local manifest before using a reference for
clean-room adapter work.

Approval for internal/reference use is separate from approval for public
redistribution. A manifest entry records identity and intended use; it does
not grant either permission. See the canonical
[source and provenance policy](../docs/04_SOURCE_AND_PROVENANCE.md) for
publication state and human-review rules.

Private reference evidence must never become a runtime or compiler network
dependency.

The checked-in `acss/4.0.1/` research notes are not a runtime dependency and do
not grant redistribution rights to any vendor code. Their current publication
status remains subject to the canonical register.
