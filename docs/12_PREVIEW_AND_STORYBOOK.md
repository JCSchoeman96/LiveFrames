# Preview and Storybook

PhoenixStorybook provides preview and verification evidence for LiveFrames
components. It does not own Catalogue metadata, lifecycle, provenance,
component API authority, or release state.

A native component becomes eligible for Catalogue admission only after its
terminal accepted native state. Every admitted CatalogueItem must reference a
valid Storybook story, which is mandatory validation evidence. The VALIDATED
transition requires a resolvable story reference and renderable canonical/default
evidence. Catalogue authority is defined in
[docs/23_CATALOGUE_ARCHITECTURE.md](23_CATALOGUE_ARCHITECTURE.md).

The accepted Phase-6 Hero story and browser evidence are recorded in
[docs/22_P6_6_NATIVE_HERO_STORYBOOK_VERIFICATION.md](22_P6_6_NATIVE_HERO_STORYBOOK_VERIFICATION.md).
That evidence verifies the native Hero preview; it does not mean Hero was
admitted to the Catalogue.
