# Approved imports

“Approved” means explicit authority for the recorded internal conversion or
intake scope. It does not mean approved for public redistribution. Approved
source bundles may produce deterministic fixtures only when they are synthetic,
sanitized, or separately cleared for public redistribution. Keep the source
provenance record with the bundle and follow
[`docs/04_SOURCE_AND_PROVENANCE.md`](../../docs/04_SOURCE_AND_PROVENANCE.md).
