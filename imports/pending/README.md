# Pending imports

Place new source bundles here until their source system, origin, version,
vendor/author where known, license status, internal-use status, and
redistribution status are recorded in `SOURCE.md` and reviewed. Unknown is a
valid recorded fact, not permission to publish. See
[`docs/04_SOURCE_AND_PROVENANCE.md`](../../docs/04_SOURCE_AND_PROVENANCE.md).
