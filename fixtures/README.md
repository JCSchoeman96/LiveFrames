# Fixtures

Fixtures are deterministic repository inputs governed by
[`docs/04_SOURCE_AND_PROVENANCE.md`](../docs/04_SOURCE_AND_PROVENANCE.md).
New fixtures may be added here only when they are synthetic, sanitized, or
explicitly approved for public redistribution. Technical review or an
unqualified “approved” label does not establish publication permission.

Approval for internal conversion is separate from approval for public
redistribution. Unknown redistribution is unresolved and is insufficient for
new public publication. Existing committed material is recorded in the
canonical policy’s status register and is not retroactively cleared by this
README.

Fixtures are not a runtime source registry. The current Bricks and ACSS
exports remain in place as historical inputs for the existing adapters; their
provenance records retain the unresolved publication facts.

- `bricks/`: structured Bricks exports
- `automatic_css/`: ACSS settings snapshots
- `html/`: explicitly redistribution-cleared HTML source fixtures
- `expected_ir/`: future Design IR golden fixtures
- `assets/`: explicitly redistribution-cleared local reference assets
