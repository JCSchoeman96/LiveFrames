# Fixtures

Fixtures are deterministic, reviewed inputs safe for repository use. They are
not a runtime source registry. Phase 0 stores the supplied Bricks and ACSS
exports here for later adapter work; no compiler code consumes them yet.

- `bricks/`: structured Bricks exports
- `automatic_css/`: ACSS settings snapshots
- `html/`: approved HTML source fixtures
- `expected_ir/`: future Design IR golden fixtures
- `assets/`: approved local reference assets
